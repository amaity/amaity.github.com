PSSE — Getting Started

Connecting the PSSE power systems engine through Python and running a basic load flow analysis.

So you want to run PSSE through Python? Here is a simple way to begin with. Let's use the following example file in the PSSE example directory: savnw.sav.

Connect the Engine

import os, sys PSSE_LOCATION = r"C:\Program Files (x86)\PTI\PSSE33\PSSBIN" sys.path.append(PSSE_LOCATION) os.environ['PATH'] = os.environ['PATH'] + ';' + PSSE_LOCATION import psspy import redirect redirect.psse2py()

Load the Case File

Feed in the case file. Note the location of the file.

import psspy, redirect SAVFILE_LOCATION = r"C:\Program Files (x86)\PTI\PSSE33\EXAMPLE\\" CASE = r"savnw.sav" psspy.case(SAVFILE_LOCATION + CASE)

Run the Power Flow

Run the Full Newton–Raphson solution. You should get the full powerflow output in your program console.

psspy.fnsl((1,0,1,0,0,0,99,1)) psspy.inibus(0) psspy.pout()

The easiest way to run the above code is to fire up IDLE (Python GUI), available from your Windows Start menu in the Python 2.7 folder. Click New Window in the File menu, paste the code, save it as test.py, and run it with Run → Run Module. If all goes as described, a powerflow output in 132-column format will appear in the IDLE console.
